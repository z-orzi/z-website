# z portfolio

一个纯静态的双语个人作品集网站。无需安装依赖，直接打开 `dist/index.html` 即可浏览。

## 本地预览

使用任意静态文件服务器打开 `dist` 目录。

## 构建与部署

项目没有构建步骤。将 `dist` 目录部署到任意静态托管服务即可。

## 技术栈

- HTML
- CSS
- 原生 JavaScript

## 结构

- `dist/index.html`：页面内容与项目数据
- `dist/styles.css`：视觉系统与响应式布局
- `dist/app.js`：双语、筛选、乱码解码交互
- `dist/assets/`：页面图片
